## 命令概览

| 命令 | 类型 | 功能描述 |
|------|------|----------|
| `status` | JSON | 设置设备状态，更新UI状态栏和情绪指示器颜色 |
| `chat` | JSON | 发送聊天消息，支持流式分片模式 |
| `clear` | JSON | 清空聊天记录，回到欢迎界面 |
| `progress` | JSON | 更新屏幕上的进度条显示 |
| `wifi` | 纯文本 | 配置Wi-Fi连接参数并保存到NVS |

## 1. 状态设置命令 `status`

### 请求格式

```json
{"type":"status","state":"listening"}
```

### 参数说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | string | 是 | 固定值 `"status"` |
| `state` | string | 是 | 状态值，见下表 |

### `state` 可选值

| 值 | 说明 | UI 颜色 |
|---|---|---|
| `idle` | 空闲 | 🟢 绿色 `#00C864` |
| `listening` | 聆听中 | 🟡 黄色 `#FFC800` |
| `thinking` | 思考中 | 🟠 橙色 `#FF8C00` |
| `replying` | 回复中 | 🟣 紫色 `#B464FF` |
| `error` | 错误 | 🔴 红色 `#FF3C3C` |

### 示例

```json
{"type":"status","state":"idle"}
{"type":"status","state":"listening"}
{"type":"status","state":"thinking"}
{"type":"status","state":"replying"}
{"type":"status","state":"error"}
```

## 2. 聊天消息命令 `chat`

### 请求格式

```json
{"type":"chat","role":"ai","text":"你好","emotion":"happy","chunk":false,"seq":0}
```

### 参数说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `type` | string | 是 | 固定值 `"chat"` |
| `role` | string | 是 | 消息角色: `user` / `ai` / `system` |
| `text` | string | 是 | 消息文本内容（最大 256 字符） |
| `emotion` | string | 否 | 情绪标签，如 `happy`, `sad` |
| `chunk` | bool | 否 | 是否为流式分片，默认 `false` |
| `seq` | int | 否 | 序列号，用于流式消息排序 |

### 消息角色

| 角色 | 说明 | 气泡颜色 |
|------|------|----------|
| `user` | 用户消息 | 🔵 蓝色 `#007ACC` |
| `ai` | AI 回复 | ⚫ 深灰 `#2D2D37` |
| `system` | 系统消息 | ⚪ 灰色 `#464650` |

### 示例

**普通消息:**
```json
{"type":"chat","role":"user","text":"你好，请介绍一下自己"}
{"type":"chat","role":"ai","text":"你好！我是Elara，你的智能助手。"}
```

**带情绪标签:**
```json
{"type":"chat","role":"ai","text":"太棒了！","emotion":"happy"}
```

**流式分片消息:**
```json
{"type":"chat","role":"ai","text":"你好","chunk":true,"seq":0}
{"type":"chat","role":"ai","text":"，我是","chunk":true,"seq":1}
{"type":"chat","role":"ai","text":"Elara","chunk":true,"seq":2}
```

## 5. Wi-Fi 配置命令 `wifi`

> ⚠️ **注意**: 此命令使用纯文本格式，非 JSON。

### 请求格式

```
wifi <ssid> <password>
```

### 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `ssid` | string | 是 | Wi-Fi 网络名称 |
| `password` | string | 是 | Wi-Fi 密码 |

### 示例

```
wifi MyHomeNetwork mypassword123
wifi CompanyWi-Fi 12345678
```

### 功能

- 将 Wi-Fi 配置保存到 NVS（非易失性存储）
- 自动尝试连接指定网络
- 连接成功后会向上位机发送事件通知

## 设备响应格式

设备在接收到命令或发生状态变化时，会向上位机发送响应消息。

### 1. 事件上报

```json
{"type":"event","source":"wifi","action":"connected"}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | string | 固定值 `"event"` |
| `source` | string | 事件来源，如 `wifi` |
| `action` | string | 事件动作，如 `connected` |

**常见事件:**

| source | action | 说明 |
|--------|--------|------|
| `wifi` | `connected` | Wi-Fi 连接成功 |
| `wifi` | `disconnected` | Wi-Fi 断开连接 |
| `wifi` | `failed` | Wi-Fi 连接失败 |

### 2. 错误上报

当上位机发送的命令格式非法或解析失败时，设备会返回错误信息。

```json
{"type":"error","msg":"JSON parse error"}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | string | 固定值 `"error"` |
| `msg` | string | 错误描述文本 |

**常见错误:**

| 错误消息 | 说明 |
|----------|------|
| `JSON parse error` | JSON 格式错误，无法解析 |
| `Unknown command` | 未知的命令类型 |
| `Missing required field` | 缺少必填字段 |

## 通信流程图

```
上位机                          设备 (ESP32-S3)
  |                                  |
  |---- JSON Command + \n --------->|
  |                                  |
  |                        [uart_rx_task]
  |                        读取 stdin 字符
  |                        按 \n 组装成行
  |                        解析为 UartCmd
  |                        发送到 FreeRTOS 队列
  |                                  |
  |                        [cmd_process_task]
  |                        从队列取出命令
  |                        调用 UI 更新函数
  |                                  |
  |<--- {"type":"error",...} -------| (解析失败)
  |<--- {"type":"event",...} -------| (状态变化)
```

---

## 注意事项

1. **每条命令必须以换行符 `\n` 结尾**，设备以此作为命令分隔符。
2. **JSON 字段名区分大小写**，请严格按照文档中的字段名书写。
3. **文本长度限制**: `text` 字段最大支持 256 字符，超出部分可能被截断。
4. **Wi-Fi 命令格式特殊**，使用纯文本而非 JSON，注意空格分隔。
5. **流式消息**需设置 `chunk: true` 并递增 `seq` 序列号，最后一条设置 `chunk: false` 表示结束。
