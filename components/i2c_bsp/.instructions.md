# i2c_bsp 组件

I2C 主机驱动封装，提供寄存器级读写和设备扫描功能。

## 硬件配置

- I2C 端口：`I2C_NUM_0`
- SDA：GPIO 47，SCL：GPIO 48
- 时钟频率：200 kHz
- 内部上拉：已启用

## API 参考

```c
void I2C_master_Init(void);                          // 初始化 I2C 主机
uint8_t I2C_writr_buff(addr, reg, *buf, len);        // 写寄存器（注意函数名拼写 wrtr）
uint8_t I2C_read_buff(addr, reg, *buf, len);         // 读寄存器
uint8_t I2C_master_write_read_device(addr, *wBuf, wLen, *rBuf, rLen); // 自定义读写
void i2c_scan(void);                                 // 扫描总线上的设备
```

## 开发规范

- 所有 I2C 操作超时为 1000ms（`i2c_master_write_to_device` 的最后一个参数）
- `I2C_writr_buff` 内部会 malloc(len+1) 拼接 reg+data，调用者无需手动拼接
- `i2c_scan` 用于调试，扫描 0x01–0x7F 地址范围
- 新增 I2C 外设时，直接调用这些函数即可，无需重复初始化总线
- 依赖：ESP-IDF `driver` 组件（已在 CMakeLists.txt 中声明）

## 常见用法

```c
// 初始化
I2C_master_Init();

// 扫描设备（调试用）
i2c_scan();

// 写一个字节到寄存器
uint8_t val = 0x01;
I2C_writr_buff(0x15, 0x00, &val, 1);

// 从寄存器读多个字节
uint8_t buf[7];
I2C_read_buff(0x15, 0x00, buf, 7);
```
