# i2c_bsp 组件

I2C 主机驱动封装，提供寄存器级读写和设备扫描功能。

## 硬件配置

- I2C 端口：`I2C_NUM_0`
- SDA：GPIO 47，SCL：GPIO 48
- 时钟频率：200 kHz
- 内部上拉：已启用

## API 参考

基于 ESP-IDF 新 I2C master 驱动（`driver/i2c_master.h`，组件 `esp_driver_i2c`）。

```c
void I2C_master_Init(void);                          // 初始化 I2C 主机总线
esp_err_t I2C_writr_buff(addr, reg, *buf, len);      // 写寄存器（注意函数名拼写 wrtr）
esp_err_t I2C_read_buff(addr, reg, *buf, len);       // 读寄存器
esp_err_t I2C_master_write_read_device(addr, *wBuf, wLen, *rBuf, rLen); // 自定义读写
void i2c_scan(void);                                 // 扫描总线上的设备
```

## 开发规范

- 驱动底层：`i2c_new_master_bus()` 建总线，`i2c_master_bus_add_device()` 按地址挂载设备（内部缓存句柄，重复地址不会重复添加），传输用 `i2c_master_transmit()` / `i2c_master_transmit_receive()`，扫描用 `i2c_master_probe()`
- 所有 I2C 操作超时为 1000ms（`I2C_XFER_TIMEOUT_MS`）
- `I2C_writr_buff` 内部会 malloc(len+1) 拼接 reg+data，调用者无需手动拼接
- 所有读写函数返回 `esp_err_t`，调用方应检查返回值（不再返回 uint8_t 截断的错误码）
- `i2c_scan` 用于调试，扫描 0x01–0x7F 地址范围
- 新增 I2C 外设时，直接调用这些函数即可，无需重复初始化总线
- 依赖：ESP-IDF `esp_driver_i2c` 组件（已在 CMakeLists.txt 中声明）

## 常见用法

```c
// 初始化
I2C_master_Init();

// 扫描设备（调试用）
i2c_scan();

// 写一个字节到寄存器
uint8_t val = 0x01;
I2C_writr_buff(0x15, 0x00, &val, 1);

// 从寄存器读多个字节
uint8_t buf[7];
I2C_read_buff(0x15, 0x00, buf, 7);
```
