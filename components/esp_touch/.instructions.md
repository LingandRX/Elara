# esp_touch 组件

触摸控制器驱动，通过 I2C 读取触摸坐标。

## 硬件信息

- I2C 地址：`0x15`
- 通信方式：I2C（依赖 i2c_bsp 组件）
- 触摸点数：单点
- 坐标精度：12 位（0–4095）

## API 参考

```c
void touch_Init(void);                    // 初始化触摸控制器（切换到正常模式）
uint8_t getTouch(uint16_t *x, uint16_t *y); // 读取触摸坐标，返回 1=按下，0=释放
```

## 寄存器格式

从地址 `0x00` 读取 7 字节：

| 偏移 | 内容 |
|------|------|
| [0]  | 模式 |
| [1]  | 保留 |
| [2]  | 触摸点数（0=释放） |
| [3]  | X 高 4 位（低 4 位有效） |
| [4]  | X 低 8 位 |
| [5]  | Y 高 4 位（低 4 位有效） |
| [6]  | Y 低 8 位 |

坐标计算：`x = (tp[3] & 0x0F) << 8 | tp[4]`

## 使用前提

- 必须先调用 `I2C_master_Init()` 初始化 I2C 总线
- 在 `main.c` 中设置 `#define EXAMPLE_USE_TOUCH 1` 启用触摸功能
- 当前默认禁用（`EXAMPLE_USE_TOUCH = 0`）

## 常见用法

```c
// 初始化
I2C_master_Init();
touch_Init();

// 读取触摸（通常在 LVGL 回调中调用）
uint16_t x, y;
if (getTouch(&x, &y)) {
    // 用户正在触摸，x/y 为坐标
}
```

## 注意事项

- 无中断引脚，仅支持轮询模式（LVGL 默认 30ms 轮询）
- `getTouch` 不会进行坐标旋转，旋转需在 LVGL 输入设备回调中处理
- I2C 超时由 i2c_bsp 组件控制（1000ms）
- `touch_Init()` / `getTouch()` 均检查 I2C 读写返回的 `esp_err_t`：读取失败时 `getTouch()` 返回 0（视为无触摸）
